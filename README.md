# AI Resume Builder

A web application that helps create a resume with the help of AI.

**Live demo:** https://ai-resum-bilder.vercel.app

## Tech Stack

- TypeScript
- Deployed on Vercel

## Getting Started

### Requirements

- Node.js 18+

### Run locally

```bash
git clone https://github.com/dmitro31/AiResumBilder.git
cd AiResumBilder
npm install
npm run dev
```

Open the address shown in the terminal in your browser.

### Production build

```bash
npm run build
npm run start
```
